# 简洁工作台交互说明（0.3.1）

## 设计范围

以用户提供的 Config Manager 截图作为布局参考：柔和灰色与低饱和绿色、顶部模块切换、左侧目录、内容分组面板及紧凑行。保留现有数据格式与文件保护，不照搬截图中的产品实现。

本轮不提供标签管理、标签筛选或按标签搜索。`tags` 是旧数据/JSON 的兼容字段，编辑或移动记录时保留，不自动清空；新记录不自动添加标签。

## 链接看板

- 看板图标是网格，分组图标是列表树；左侧树保留完整目录层级与连接线，可横向滚动并拖宽。
- 当前看板有一个紧凑标题栏。“添加链接”常驻，编辑、批量选择、分组管理及导出放入更多菜单。导入和全库操作放在左侧底部。
- 每行显示名称、域名、复制、展开和更多。完整 URL / 备注按需展开，长名称省略但悬停可读完整内容。
- 鼠标单击正文短暂等待以区分双击；双击取消待打开动作并进入编辑弹窗。键盘 Enter 直接打开，不必等待。复制、展开、菜单和输入不触发打开。
- 链接编辑集中在一个弹窗，包含名称、地址、分组和多行备注，保存后一次更新。Ctrl/Command + Enter 保存，IME 候选确认不提交。
- 分组可折叠，标题加号直接向该组添加链接；右键和更多菜单可编辑、新建子组、导出、排序、独立为看板或保留内容删除。

## Kubeconfig

- 左侧环境分组直接包含配置，不再另设一列配置列表。分组与配置均可排序，组可折叠；拖到折叠分组上会临时展开。
- 单击配置后右侧立即使用其真实路径生成命令。来源、完整路径、环境变量名称、所属分组在首屏；可复制路径和定位本机源文件。
- Context / 命名空间、复制格式 / 终端各在同一行对齐，附加参数按需展开。预览为一段原始文本，复制内容无行号或提示符。
- 导入仍有文件、递归目录、剪贴板三个入口，不要求特定后缀；已移除标签输入。
- 双击配置或“查看配置”打开原文。名称、环境变量、分组、路径在上方，正文集中显示。Context、集群地址和文件信息在可展开区域；正文默认只读，切换编辑后才可修改。
- 保存等待校验、文件写回和记录保存完成，失败保留草稿。删除只移除记录；删除分组会迁移配置，作为一次可撤销事务提交。

## 命令管理

- 逐行复制按钮在悬停对应代码行、悬停行号旁或编辑当前行时显示；空白行不放置按钮，固定留白避免内容跳动。
- 行复制保持光标及选区，行号随编辑同步。键盘可使用编辑器下方“复制选中 / 当前行”，整段复制入口保留。
- 语言标题与下拉框作为一个横向整体，窄窗口整体换行，不把标题挤成竖排。

## 拖拽与批量

- 手柄发起拖动，保留小型预览。分组边缘显示插入线，中央高亮表示移入；链接和配置之间只排序，采用目标所属分组。
- 看板、侧栏分组、内容分组、链接、环境分组及配置共用拖拽规则；防止把分组放进自身或后代。
- 批量工具按需出现，并通过正常换行保留所有按钮；不使用浮动覆盖内容或负边距叠放工具栏。
- 普通删除/移动有库 Undo；文本编辑器 Undo 与源文件备份的职责保持分开。

## 实现落点

应用壳、业务视图与编辑器拆分到 `App.tsx`、`features/bookmarks`、`features/kube`、`features/commands`。共用菜单、分组树、面板、落点及持久化继续复用。`workspace-simple.css` 统一主题、尺寸和工作区结构；输入法确认判断在 `lib/presentation.ts`。

## 验证

自动回归覆盖单击/双击区别、编辑/复制互不触发、完整备注、旧字段保留、标签不参与搜索、侧栏与内容面板拖拽、配置选择到命令、导入不出现标签、分组删除一键撤销，以及原有文件写回失败保护。

浏览器检查与系统原生检查分开记录：浏览器可检查实际色彩、对齐、展开、菜单、弹窗、主题和溢出；JSDOM 拖拽验证业务事件与持久化，不代表真实 macOS / Windows 指针拖拽已通过。个人数据不作为测试夹具或截图素材上传。
